# SpaceKai v0.3.6

> Released 2026-09-03

## What's changed

v0.3.6 is a focused Settings/UX patch on the v0.3.5 code line. Same
`applicationId`, same signing certificate, versionCode 84 > 83 — the
release-signed APK installs in place over v0.3.5 with data preserved.

### Changed
- Settings: the top gap is no longer a hardcoded spacer — the first section
  clears exactly the measured height of the floating top app bar (minus the
  content inset already applied), so the screen opens with the first section
  right under the bar whether it is expanded or collapsed.
- Settings: the "Buy me a coffee" row (which silently opened GitHub Sponsors)
  is replaced by two explicit rows — Ko-fi ("Soutenir SpaceKai / Souanpt",
  ko-fi.com/souanpt) and Site (simpmusic.org) — that state where they go.
  Ko-fi now opens the maintainer's real page (also declared `ko_fi: souanpt`
  in .github/FUNDING.yml); Site opens simpmusic.org, the only project site URL
  this repo carries (the fork declares no separate homepage on GitHub).
- Settings: Spotify, Discord, SponsorBlock and Last.fm now live under one
  "Intégrations" section (collapsed by default, single-open like every other
  section) instead of three loose top-level entries; Last.fm is no longer
  mis-gated on the Discord section. No functionality changed — pure
  presentation reorganisation, nothing duplicated.

### Honesty note

All changes above are compile / test / gate-verified (shell gates,
`:composeApp:compileKotlinMetadata`, full `:composeApp:jvmTest`, and a full
`:androidApp:assembleRelease` on the same code before the version bump). The
on-device run — Settings top gap open/closed + scrolling, Intégrations
grouping without stale duplicates, Ko-fi/Site link targets, and the
v0.3.5→v0.3.6 in-place update flow — is still to be executed on a real phone
before these lines are considered runtime-proven.
