# SpaceKai v0.3.2

> Released 2026-08-31

## What's changed

Small release on the SimpMusic 2.0.0 base: the upstream (SimpMusic) version
detection is now honest and never hardcodes the "latest" version.

### Fixed — upstream detection (Settings → Updates → SimpMusic — Upstream)
- "Base intégrée" and "Dernière release officielle" are now two clearly
  separated facts. The base is a build-time constant (`v2.0.0`); the latest
  official release is fetched live from GitHub (`/releases/latest`, never
  hardcoded).
- An errored / offline / rate-limited check no longer claims "compatible" or
  "à jour" — it shows "Impossible de vérifier actuellement" plus the last-known
  version and last-check time.
- When the integrated base is NEWER than the official release, the app says
  "already newer" instead of a false "⚠ new version" warning, and never offers
  a downgrade.
- Version comparison is now semantic: a re-cut tag (e.g. `v0.3.1-1`) no longer
  triggers a false update against `v0.3.1`.
- The SpaceKai update row compares installed vs. latest by semantic version too
  (a re-cut tag is the same version — no false "Mettre à jour"): on Android the
  universal APK is downloaded, SHA-256 verified and installed in-app; desktop
  falls back to the browser.

### Known / not finished (honest)
- As with v0.3.1, the **full on-device path** (download → SHA → Android
  installer) and the detection UI are only compile/test/gate/CI verified — they
  have **not** been run on a physical phone. These stay PARTIALLY IMPLEMENTED
  in the feature audit until verified on a device.
- Several SpaceKai feature flags remain PARTIALLY / NOT IMPLEMENTED — the
  feature-audit block below is the complete list; nothing here claims them done.
