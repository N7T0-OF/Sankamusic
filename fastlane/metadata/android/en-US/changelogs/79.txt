# SpaceKai v0.3.1

> Released 2026-08-31

## What's changed

This release finishes the two P0 features on top of the SimpMusic 2.0.0 base.

### P0-1 — Real in-app update manager
- Settings → Update now detects the latest GitHub release and resolves the
  **universal** APK automatically (ignores debug / unsigned / per-ABI splits).
- Internal download with real byte-progress, speed and remaining-time.
- **SHA-256 verification** against `SHA256SUMS.txt` before install — a
  corrupted or tampered APK is refused, never installed.
- Install goes through the Android Package Installer (user confirms).
- Desktop falls back to the browser (no simulated install).
- The SimpMusic "upstream" block is informational only — SpaceKai never
  installs the official SimpMusic APK over itself.

### P0-2 — Settings reorganized and collapsed by default
- Every Settings section is now **closed by default**; opening one smoothly
  closes the previous one.
- Settings are grouped per category (Content, Playback, Listening history,
  Lyrics, AI, Spotify, Discord, SponsorBlock, Downloads, Audio, Storage,
  Backup, About).
- Added a dedicated collapsed **Downloads** and **Audio** section.
- Collapsed sections are not rendered, improving scroll and response.

### Other
- Bug fixed: **Android build crash** from a non-ASCII string in the Android
  updater source (rewritten ASCII-safe).
- Settings toggle flags now apply immediately (Compose recomposition layer).

### Known / not finished (honest)
- The **full device install path** (download → SHA → Android installer) is
  only compile + CI-verified — it has **not** been run on a physical phone.
  The update flow and collapsed settings are marked PARTIALLY IMPLEMENTED in
  the feature audit until verified on a device.
- Many SpaceKai feature flags remain PARTIALLY / NOT IMPLEMENTED (see the
  feature-audit block below); nothing here claims them done.
