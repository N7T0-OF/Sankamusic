# SpaceKai v0.3.5

> Released 2026-09-03

## What's changed

v0.3.5 is a focused patch release on the v0.3.4 code line (the v0.3.3 build
that passed Gate 0 on device). It carries three UI fixes from PR #2 plus one
release-tooling fix. Same `applicationId`, same signing certificate,
versionCode 83 > 82 — the release-signed APK installs in place over v0.3.4
with data preserved.

### Fixed
- Settings: the oversized vertical gap at the top of the Settings screen
  (ambient-glow padding of ~376dp) is reduced to a normal app-bar inset, so
  the screen no longer opens with a large empty band.
- Navigation: Analytics stays available in compact / minimalistic navigation
  whenever local tracking is enabled — only Mix-for-you is removed by the
  compact mode.
- Navigation: one shared selection contract across the flat bar, the rail
  and the Android liquid-glass bar — hiding the currently selected tab
  reroutes to a visible destination, hiding Search removes its FAB, and
  hiding every tab keeps Home reachable.
- Tooling: `generate-fastlane-changelog.sh` now picks the greatest tag
  strictly below the current version-name (v0.3.4 for this release) instead
  of the second-highest tag overall, which on the 0.3.x line resolved to
  v1.9.0 and made the range unusable.

### Honesty note

All four fixes above are compile / test / gate / CI-verified (shell gates,
11 focused `NavCustomizationTest` cases, full `:composeApp:jvmTest`,
`compileKotlinMetadata`, `assembleRelease`, CI release build). The on-device
Gate 0 acceptance run — Settings gap, Analytics in compact, hide-selected
reroute, hidden-Search FAB removal, per `docs/E2E-NAV-SETTINGS-V035.md` with
`scripts/device-acceptance-nav-settings.sh` — is scheduled right after
publication and must return ALL PASS before these lines are considered
runtime-proven.
